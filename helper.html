RapidCat Helper

An optional separate companion for additional App Store features. RapidCat does not download or install it automatically.

Works without Helper

Shortcuts, Leader Key, clipboard, text tools, on-device voice input, Command Bar, dictionary, notes, Caffeinate and file search in selected folders.

Requires Helper

Window control/layout/picker/switcher and Click Labels; user shell scripts with per-command approval; Lock Screen, Toggle Dark Mode and Empty Trash; HID-level hardware key remapping; search across your home folder.

Distribution

Signed and notarized Helper 1.0 (1), macOS 14+, Intel and Apple Silicon. This is a prerelease: end-to-end runtime integration is still being verified. Open the DMG, drag RapidCat Helper to Applications, launch it yourself, then allow background operation and Accessibility when requested. Confirm its connection in RapidCat Settings → General.

Setup and connection

Install it separately, launch it yourself, and allow background operation and Helper Accessibility when requested. Check the connection in RapidCat Settings → General. Pro access and these permissions are separate. Shell commands may access files or the network according to the commands you approve; review each command.
