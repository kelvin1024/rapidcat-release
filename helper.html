RapidCat Helper

App Store 버전의 추가 기능을 위한 선택 사항인 별도 앱입니다.

Helper 없이 사용할 수 있는 기능

단축키와 Leader Key, 클립보드, 텍스트 도구, 기기 내 음성 입력, Command Bar, 사전, 메모, Caffeinate와 사용자가 선택한 폴더의 파일 검색을 사용할 수 있습니다.

Helper가 필요한 기능

  • 창 제어·레이아웃·선택·전환과 클릭 라벨
  • 명령별 승인을 받는 사용자 Shell Script
  • 화면 잠금·다크 모드 전환·휴지통 비우기
  • HID 수준의 하드웨어 키 재매핑
  • 홈 폴더 전체 파일 검색

배포 상태

Helper 공개 배포 파일은 준비 중입니다. 검증된 서명·공증 배포 파일이 준비되면 이 페이지에 설치 안내와 다운로드를 추가합니다.

설정과 연결 확인

Helper를 별도로 설치한 경우 앱을 직접 실행하고, 요청되는 백그라운드 실행 및 Helper의 손쉬운 사용 권한을 허용하세요. RapidCat 설정 → General에서 Helper 연결 상태를 확인할 수 있습니다. RapidCat은 Helper를 자동으로 다운로드하거나 설치하지 않습니다.

Shell Script는 실행 내용에 따라 파일과 네트워크에 접근할 수 있습니다. 승인하려는 명령 내용을 확인하세요.

An optional companion for the App Store build

RapidCat works without the helper: shortcuts, clipboard tools, text tools, on-device voice input, the command bar, dictionary, notes, Caffeinate, and file search in chosen folders remain available.

Features that use the helper

  • Window control, layout, picker, switcher and Click Labels
  • User-written shell actions with per-command approval
  • Lock Screen, Toggle Dark Mode and Empty Trash
  • Hardware key remapping at HID level
  • File search across your home folder

Distribution

The public helper download is being prepared. Installation instructions and a download will be added when a signed and notarized release is ready.

Setup and connection

If you have installed the helper separately, launch it yourself and allow background operation and its Accessibility permission when requested. Check the connection in RapidCat Settings → General. RapidCat does not automatically download or install the helper.

Shell scripts may access files or the network according to the commands you approve. Review each command before approving it.
