Applications

Drag to Applications

Open the DMG and drag RapidCat Helper to the Applications folder. Then open Helper from Applications to set up permissions.

Works without Helper

Shortcuts, Leader Key, clipboard, text tools, on-device voice input, Command Bar, dictionary, notes, Caffeinate and file search in selected folders.

Requires Helper

Window control/layout/picker/switcher and Click Labels; user shell scripts with per-command approval; Lock Screen, Toggle Dark Mode and Empty Trash; HID-level hardware key remapping; search across your home folder.

Distribution

Signed and notarized for macOS 14 and later. Supports Apple Silicon and Intel. Drag RapidCat Helper to Applications, open it, then follow the permission guidance. Confirm its connection in RapidCat Settings → General.

Setup and connection

Use its background-operation and Accessibility guidance buttons to open the relevant macOS settings, then grant the requested permissions yourself. The buttons do not automatically grant permissions. Check the connection in RapidCat Settings → General. Pro access and these permissions are separate. Review each shell command before approval because it may access files or the network. The installed Helper starts and quits with RapidCat. Manage launch at login in RapidCat settings.
