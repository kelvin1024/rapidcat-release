# RapidCat public release pages

Public website and download information for RapidCat, a keyboard productivity app for macOS 14+.

Website: https://kelvin1024.github.io/rapidcat-release/

This repository contains only reviewed static website files and distribution information. The RapidCat application source remains private.

The signed and notarized optional Helper is available as a prerelease: https://github.com/kelvin1024/rapidcat-release/releases/tag/helper-v1.0-build1

The website follows browser language preferences and supports nine languages, with a manual language selector.
