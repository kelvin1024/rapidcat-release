Support

Contact j1024kh@gmail.com with your macOS version, RapidCat version, distribution and reproduction steps. Do not send clipboard contents or sensitive files.

Pro access and restoration

Menu bar → RapidCat Pro shows access, Restore Purchases and Manage Subscription. Sign in to the App Store with the purchasing Apple account to restore. If restoration fails, check authentication and internet access, then retry. Expiration or refund/revocation restricts tool execution; settings, tutorials, licenses and viewing/exporting/deleting existing data remain available. Pro does not grant Helper connections or macOS permissions.

Shortcuts and tutorial

Check Accessibility and, in the App Store build, Input Monitoring in System Settings → Privacy & Security. Check General’s permission guidance and that the shortcut is enabled. Replay Tutorial from the menu bar or General.

Voice input

Download and select a model in Voice Input and allow microphone access. Model downloads need internet; transcription stays on your Mac.

Unavailable tools

Window actions, Click Labels and some system tools need Helper. Without it, select search folders in Settings. If auto-paste is off, paste results with ⌘V.
