Pro 이용권 확인과 구매 복원

App Store 버전에서 생산성 도구를 실행하려면 활성 Pro 이용권이 필요합니다. 메뉴 막대 → RapidCat Pro에서 상태를 확인하세요. 이미 구매했다면 구매에 사용한 Apple 계정으로 App Store에 로그인하고 같은 화면의 구매 복원(Restore Purchases)을 선택하세요. 구독 관리(Manage Subscription)는 Apple 구독 관리 화면을 엽니다. 구독 만료·환불에 따른 권한 철회 후에는 도구 실행이 제한될 수 있지만 설정·튜토리얼·라이선스·기존 저장 데이터는 확인할 수 있습니다.

Helper 연결이나 macOS 권한은 Pro 이용권과 별개입니다. 출시 전 상품이 아직 준비되지 않은 경우 구매할 수 없으며, 실제 상품과 체험 조건은 구매 안내 및 Apple 구매 화면을 확인하세요. 복원이 실패하면 App Store 인증·인터넷 연결을 확인하고 재시도하세요.

단축키가 동작하지 않습니다

시스템 설정 → 개인정보 보호 및 보안에서 RapidCat의 손쉬운 사용 권한을 확인하세요. App Store 버전에는 입력 모니터링 권한도 필요합니다. 앱 설정 → General에서 권한 안내를 확인하고 단축키가 활성화되어 있는지 확인하세요.

처음부터 안내를 다시 보고 싶습니다

메뉴 막대의 Tutorial 또는 설정 → General의 튜토리얼 다시 보기 기능을 사용하세요.

음성 입력이 시작되지 않습니다

설정 → Voice Input에서 음성 모델을 내려받고 선택하세요. 마이크 권한이 필요합니다. 모델 다운로드에는 인터넷 연결이 필요하고, 음성 변환은 Mac에서 처리합니다.

일부 도구가 비활성화되어 있습니다

App Store 버전에서 창 제어, 클릭 라벨과 일부 시스템 도구는 선택 사항인 Helper가 연결되어야 합니다. Helper 안내를 확인하세요. Helper 없이 파일 검색을 사용할 때는 설정에서 검색할 폴더를 추가하세요.

자동 붙여넣기가 꺼져 있습니다

결과가 클립보드에 복사되면 대상 앱에서 ⌘V로 붙여넣으세요.

Pro access and Restore Purchases

Productivity-tool execution in the App Store build requires active Pro access. Check its status in the menu bar → RapidCat Pro. If you already purchased, sign in to the App Store with the purchasing Apple account and choose Restore Purchases on that screen. Manage Subscription opens Apple’s subscription management page. Expiration or refund/revocation can restrict tool execution, while settings, tutorials, licenses and existing data remain viewable.

Pro access is separate from helper connection and macOS permissions. Products that are not ready before release cannot be purchased. Check the purchase information and Apple’s purchase confirmation for actual products and trials. If restoration fails, check App Store authentication and internet access, then retry.

Shortcuts do not work

Check RapidCat’s Accessibility permission in System Settings → Privacy & Security. The App Store build also needs Input Monitoring. Settings → General shows permission guidance. Check that your shortcut is enabled.

Replay the tutorial

Choose Tutorial in the menu bar or replay it from Settings → General.

Voice input does not start

Download and select a speech model in Voice Input settings and allow microphone access. Downloads need an internet connection; transcription runs on your Mac.

Some tools are unavailable

Window tools, Click Labels and certain system actions in the App Store build require the optional helper. See the helper guide. For file search without the helper, add the folders you want to search in Settings.

Auto-paste is off

Paste the clipboard result into the target app with ⌘V.
