Getting started

Open Settings from the menu bar. Settings, tutorials, licenses, and viewing/exporting/deleting existing saved data remain available without Pro. Executing productivity tools in the App Store build requires an active verified subscription, eligible trial or lifetime entitlement. Open RapidCat Pro to purchase or restore. A trial starts after an eligible subscription is confirmed with Apple, not after installation.

1. Permissions

Follow General’s Accessibility and, for the App Store build, Input Monitoring guidance. Global shortcuts pause while Settings has focus; close it to try them.

2. Leader Key

Configure your key combination, close Settings and open the panel to launch an app or action. Configure direct shortcuts separately.

3. Clipboard and text

Review Clipboard settings and copy non-sensitive sample text to try history and text tools. When auto-paste is off, paste with ⌘V.

4. File search and tools

Without Helper in the App Store build, first select search folders. Explore Command Bar, dictionary, notes and Caffeinate.

5. Voice input

Download and select a model in Voice Input and allow microphone access. Use your shortcut with hold-and-release or double-tap start/stop. Downloads need internet; transcription runs on your Mac.

6. Optional Helper

Window tools, Click Labels and some system actions require the separately installed Helper. Core tools work without it.

7. Practice again

Replay Tutorial from the menu bar or Settings → General.
