App Store 버전: 먼저 Pro 이용권 확인

메뉴 막대 → RapidCat Pro에서 구독 또는 평생 이용권과 구매 복원을 확인하세요. 생산성 도구를 실행하려면 활성 Pro 이용권이 필요합니다. 구매하지 않아도 설정·튜토리얼·라이선스·기존 저장 데이터는 확인할 수 있습니다. 7일 체험은 자격 있는 계정이 Apple에서 구독을 신청·확인한 뒤 시작하는 소개 혜택이며 설치만으로 시작되지 않습니다.

현재 출시 준비 중이며 실제 상품·가격·체험은 Apple 구매 화면을 기준으로 확인하세요. 구매 안내를 먼저 읽고 Pro 활성화 후 아래 도구를 사용해 보세요.

1. 권한과 설정

RapidCat을 실행하고 메뉴 막대에서 설정을 여세요. General의 안내에 따라 손쉬운 사용 권한을 확인하고, App Store 버전에서는 입력 모니터링도 확인하세요. 설정 창이 활성화되어 있으면 전역 단축키가 일시 중지되므로 실제 동작은 설정 창을 닫고 확인하세요.

2. Leader Key

설정에서 Leader Key를 선택하고 사용할 키 조합을 지정하세요. 설정 창을 닫고 지정한 키를 눌러 패널을 열어 앱이나 액션을 실행해 보세요. 직접 단축키도 별도로 설정할 수 있습니다.

3. 클립보드와 텍스트

Clipboard 설정에서 기록과 동작을 확인하세요. 민감하지 않은 예제 텍스트를 복사해 기록을 확인하고, 텍스트 도구를 실행해 보세요. 자동 붙여넣기를 사용하지 않으면 결과를 ⌘V로 붙여넣을 수 있습니다.

4. 파일 검색과 도구

App Store 버전에서 Helper 없이 검색하려면 검색할 폴더를 먼저 선택하세요. Command Bar, 사전, 메모, Caffeinate도 살펴보세요.

5. 음성 입력

Voice Input 설정에서 모델을 내려받고 선택한 뒤 마이크 권한을 허용하세요. 지정한 단축키로 녹음을 시작합니다. 키를 누르고 있다가 놓는 방식이나 두 번 눌러 시작·중지하는 방식을 사용할 수 있습니다. 모델 다운로드에는 인터넷이 필요하고 음성 변환은 Mac에서 처리합니다.

6. 선택 사항: Helper

App Store 버전의 창 제어·클릭 라벨·일부 시스템 기능에는 별도 Helper가 필요합니다. 핵심 기능은 Helper 없이 사용할 수 있습니다. 설치와 연결 방법은 Helper 안내를 확인하세요.

7. 앱 안에서 다시 연습

메뉴 막대의 Tutorial 또는 설정 → General에서 튜토리얼을 다시 열 수 있습니다. 앱 안의 튜토리얼은 Leader Key와 주요 기능을 단계별로 안내합니다.

Getting started

App Store build: check Pro access first

Open the menu bar → RapidCat Pro for subscription or lifetime options and Restore Purchases. Productivity-tool execution requires active Pro access. Settings, tutorials, licenses and existing saved data remain viewable without a purchase. A seven-day trial is an introductory offer for eligible accounts after confirming a subscription with Apple; installation alone does not start it.

Release preparation is in progress. Actual products, prices and trial availability are shown by Apple. Read the purchase information, then try the tools below with Pro active.

1. Permissions and settings

Launch RapidCat and open Settings from the menu bar. Follow General’s guidance for Accessibility and, in the App Store build, Input Monitoring. Global shortcuts pause while Settings has focus, so close it before trying a shortcut.

2. Leader Key

Choose a key combination in Leader Key settings. Close Settings, press your configured key, and use the panel to launch an app or action. Direct shortcuts can be configured separately.

3. Clipboard and text

Review your Clipboard settings. Copy non-sensitive sample text to try history and text tools. When auto-paste is off, paste the result with ⌘V.

4. File search and tools

For file search without the helper in the App Store build, select the folders to search first. Explore the command bar, dictionary, notes and Caffeinate.

5. Voice input

Download and select a model in Voice Input settings, then allow microphone access. Record with your configured shortcut using hold-and-release or double-tap start/stop. Model downloads need the internet; transcription runs on your Mac.

6. Optional helper

Window tools, Click Labels and certain system actions in the App Store build use a separate helper. Core features work without it. See the helper guide for setup and connection.

7. Practice in the app

Replay Tutorial from the menu bar or Settings → General. The in-app tutorial walks through the Leader Key and major features.
